How the simulation works

Each cell holds a value and an algotype. In every round, cells act once each, in random order, which stands in for the parallel threads in the paper.

Bubble cells compare themselves with a random neighbour and swap if out of order. Insertion cells move left only when everything to their left is already sorted. Selection cells keep a target position starting at the far left, swap with whoever is there if that cell should come after them, and otherwise move the target one step right.

The run ends when a full round changes nothing. Frozen cells never act. Movable frozen cells can still be swapped by others; immovable ones block swaps.

Things to try. Run the batch on Bubble + Selection, then tick the control and run it again: the clustering hump should vanish. Add frozen cells and compare the two progress traces. The pairs metric dips. Inversions never go backwards, because every swap here exchanges an out-of-order pair. Whether the system "goes backwards" depends on how you measure progress.
